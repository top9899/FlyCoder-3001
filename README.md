# 🪰 МУХА-КОДЕР 3001 (FlyCoder 3001)
> **🧬 КИБЕР-ЛАБОРАТОРИЯ: Нейроинтерфейс мозга мухи дрозофилы на основе Q-Learning (3D Model v2.0)**

Интерактивный научно-фантастический симулятор виртуальной лаборатории в стиле киберпанк. Проект моделирует биологический мозг мухи, которая с помощью алгоритмов машинного обучения с подкреплением пытается освоить синтаксис языка Go и написать свой первый код.

---

## ⚡ Почему этот проект по-настоящему крут?

1. **Реальное 3D на чистой математике:** Трехмерная модель мозга вычисляется в реальном времени с помощью тригонометрических матриц вращения. Никаких тяжелых движков (Unity/Unreal) — только чистый Python и геометрия.
2. **Биологическая анатомия:** Архитектура сети копирует структуру реального мозга дрозофилы. Оптические лобы (зрение) активируются при анализе текста, моторные нейроны вспыхивают при нажатии клавиш, а центральный комплекс отвечает за обработку ошибок.
3. **ИИ «Без обмана» (Q-Learning):** Алгоритм Reinforcement Learning основан на формуле Беллмана без использования сторонних нейросетевых библиотек (TensorFlow/PyTorch). Поведение мухи эволюционирует от полного хаоса до осознанного выбора.
4. **Атмосферный Cyberpunk UI:** Виртуальный терминал Python IDE, датчики жизнеспособности, шкала цифрового дофамина (сахара) и динамические вспышки активности синапсов превращают математический код в зрелищную симуляцию.

---

## 🛠 Зависимости проекта

Скрипт использует минимальный набор внешних библиотек для обеспечения высокой скорости расчетов:
* `pygame` — для создания графического интерфейса и рендеринга 3D.
* `numpy` — для быстрых матричных вычислений яркости свечения нейронов.

---

## 🚀 Инструкция по установке и запуску

Выполните эти три простые команды в вашем терминале (PowerShell или CMD), чтобы запустить симуляцию:

### 1. Перейдите в папку с проектом
```bash
cd "Путь/к/вашей/папке/муха"
```

### 2. Установите необходимые зависимости через Pip
```bash
pip install pygame numpy
```

### 3. Запустите Муху-Кодера 3001
```bash
python FlyCoder3001.py
```
